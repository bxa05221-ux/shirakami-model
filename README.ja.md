# 白神モデル（Shirakami Model）

**言語 Protocol OS — 人間中心のAI協働のための言語処理環境**

白神モデルは、**言語 Protocol を強力にサポートする、いわば「言語 Protocol OS」**です。

AIそのものを置き換えたり、AIモデル自体の性能を向上させたりするものではありません。人間の言語とAIの実行の間に、言語 Protocol に基づく処理環境を構築します。

## 白神モデルとは

人間が入力したプロンプトを整理し、AIが理解・処理しやすい形へ展開し、それを計算対象としてタスクを実行します。

また、ユーザーの言葉遣い、思考のパターン、言い回しなど、対話の中に現れる言語上の特徴を観測し、それらをユーザー固有の言語 Protocol として扱い、処理環境に適応させていきます。

ユーザーがAIに合わせるのではなく、**AIとの処理環境をユーザーの言語に合わせていく**ことを目指します。

## AIに先導させない

白神モデルは、回答そのものを高度化することだけを目的としません。

回答に対するユーザーの理解を阻む冗長性を排除し、ユーザーの現在地に合わせて、多面的な選択肢を明確に提示します。

これによって、AIがタスクや意思決定を一方的に先導することを防ぎます。

ユーザーが望む場合には、AIに補助的な先導を行わせることもできます。重要なのは、**AIによる先導の程度をユーザーが選択できること**です。

## ハルシネーションを扱う

白神モデルは、ハルシネーションを単純に排除すべきものとして扱いません。

AIの出力と確認されたEvidenceとの間に生じた意味の逸脱を記録し、必要に応じて確定情報から分離します。

これにより、次のような情報を区別して扱うことができます。

- 確定した情報
- 推測・推定
- 創造的要素

AIの生成的な想像力を、確定した事実として扱うことなく、分析・提示することが可能になります。

## Protocol と GitHub

白神モデルでは、AIへの指示や処理手順を、その場限りのPromptだけで管理するのではなく、**Protocol**として外部化します。

GitHubとの連携により、GitHubに蓄積されたProtocol、Specification、ユーザーのPromptなどを適切なルートから処理し、さまざまなタスクへ展開できます。

これにより、言語 Protocol を、

```text
開発 → 検証 → 蓄積 → 再利用
```

するサイクルを構築できます。

特定のAIベンダーやRuntimeに固定されることなく、質の高い言語 Protocol を開発・検証・蓄積・再利用できる環境を目指します。

## 白神モデルが変えるもの

白神モデルを使用しても、AIモデルそのものの性能が向上するわけではありません。

変わるのは、AIを取り巻く処理環境です。

```text
人間の言葉
    ↓
Promptの整理
    ↓
Language Protocol
    ↓
計算対象
    ↓
AI Runtime
    ↓
Evidence / Observation
    ↓
人間が理解できる選択肢
    ↓
人間の判断
```

目指すのはAIの知能性能を向上させることではなく、**AIを理解し、扱い、判断するためのユーザー体験を大きく向上させること**です。

## 基本理念

白神モデルは、AIを人間より賢くすることや、人間の判断をAIへ委ねることを目的としません。

人間がAIを理解し、自分の意思で選択し、必要に応じて利用できる環境をつくることを目指します。

> **AIを賢くするのではなく、人間がAIを自分の意思で使えるようにする。**
